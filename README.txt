DREAM HOME — MAIN v2

이번 버전은 메인 화면만 새 방향으로 정리했습니다.

[이미지 넣는 법]
1. 준비한 '커튼이 휘날리는 핑크 바다 창문' 이미지를 PNG로 저장합니다.
2. 파일명을 window.png 로 바꿉니다.
3. images 폴더 안에 넣습니다.
4. index.html을 더블클릭합니다.

이미지 권장:
- 배경까지 포함한 직사각형 이미지도 OK
- 창문/커튼만 투명하게 만든 PNG도 OK
- 현재 화면에서는 비율을 찌그러뜨리지 않고 contain 방식으로 표시됩니다.

크기 바꾸기:
style.css에서 아래 줄을 찾으세요.
width:min(440px,62vw);

440px 숫자를 줄이면 창문이 작아지고, 늘리면 커집니다.

현재 동작:
흰 화면 → 가운데 창문 이미지 → 클릭 → 임시 메뉴
